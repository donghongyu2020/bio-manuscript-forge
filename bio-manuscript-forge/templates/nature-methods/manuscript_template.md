# Nature Methods 论文结构模板

## 字数限制

- Main Text: ~2500 words
- Methods: ~1500 words
- Figure: 5-6 个
- 每个 Figure: 4-6 panels

## 结构

```
Main Text (~2500 words)
├─ Introduction (1-2 paragraphs, ~400 words)
├─ Results (4-5 sections, ~1800 words)
│   ├─ 2.1 Model Overview (Figure 1)
│   ├─ 2.2 [Task 1] (Figure 2)
│   ├─ 2.3 [Task 2] (Figure 3)
│   ├─ 2.4 [Task 3] (Figure 4)
│   └─ 2.5 [Task 4] (Figure 5)
├─ Discussion (1 paragraph, ~300 words)
└─ Methods (~1500 words, 在线补充)

Supplementary
├─ Supplementary Figure 1-10
├─ Supplementary Table 1-5
├─ Supplementary Methods
└─ Supplementary Note
```

## Figure 标准

- 尺寸：单栏 89mm，双栏 183mm
- 分辨率：300 dpi
- 字体：Arial 或 Helvetica，6-12 pt
- 颜色：避免红绿对比，考虑色盲友好

## 图注格式

```markdown
> **Figure X: [Title].** 
> 
> a) [Panel a description]. 
> b) [Panel b description with statistics]. 
> c) [Panel c description]. 
> d) [Panel d description]. 
> e) [Panel e description].
```

## 引用格式

- 数字引用：[1], [2,3], [4-7]
- 格式：Nature Methods style
