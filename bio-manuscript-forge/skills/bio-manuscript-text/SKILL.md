# bio-manuscript-text

**Step 7: 论文文案生成**

生成完整论文文案：Introduction（5段）+ Results + Discussion + Methods。

## 功能

1. Introduction（5段）：领域介绍 → 相关工作 → 不足 → 方法 → 意义
2. Results（2.1-2.5）：Model Overview → Figure 2-5 正文
3. Discussion：优势 → 对比 → 发现 → 局限 → 未来
4. Methods：预处理 → 模型 → 训练 → 指标 → 分析 → Baseline

## 输入格式

```
topic: [研究主题]
figure_designs: [Figure 设计文档]
innovation: [用户创新点]
base_work: [原有工作]
metric_system: [指标体系]
analysis_system: [分析方法]
paper_count: [已有工作数量]
related_papers: [相关工作列表]
target_journal: [目标期刊]
```
