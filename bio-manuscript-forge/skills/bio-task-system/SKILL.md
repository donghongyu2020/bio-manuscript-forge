# bio-task-system

**Step 2: 任务体系构建**

识别领域主要任务分类，设计层层递进的任务层级。

## 功能

1. 搜索该领域的主要任务分类
2. 识别任务层级（Level 1-4）
3. 确保任务难度递进
4. 为每个任务匹配后续数据集

## 输入格式

```
topic: [研究主题]
paper_count: [已有工作数量，从 Step 1 获得]
```

## 执行流程

### Step 2.1: 任务分类搜索

**如果有大量已有工作（paper_count >= 5）**：

```
策略：从已有工作提取任务分类

for paper in top_papers:
    # 阅读论文 Methods 部分
    tasks = extract_tasks_from_paper(paper)
    
    # 提取示例：
    # "我们进行了垂直整合（同一细胞的多模态）"
    # "水平整合（不同区域的空间配准）"
    # "马赛克整合（部分模态缺失推断）"

# 汇总任务类型
task_taxonomy = aggregate_tasks(tasks)
```

**如果没有大量已有工作**：

```
策略：向上级领域借用任务分类

# 找上级领域
parent_domain = find_parent_domain(topic)
# 例如：空间多组学整合 → 单细胞多组学整合

# 搜索上级领域的任务分类
parent_tasks = search_tasks_in_domain(parent_domain)

# 适配到当前领域
task_taxonomy = adapt_tasks_to_domain(parent_tasks, topic)
```

### Step 2.2: 任务层级设计

**层级定义**：

```
Level 1（最简单）：基础任务
- 数据复杂度：单一来源、完整数据
- 技术难度：简单映射/整合
- 生物学意义：技术验证

Level 2（中等）：进阶任务
- 数据复杂度：多来源、需配准
- 技术难度：配准/对齐
- 生物学意义：应用分析

Level 3（较难）：挑战任务
- 数据复杂度：部分缺失、需推断
- 技术难度：推断/补全
- 生物学意义：新发现潜力

Level 4（最难）：创新任务
- 数据复杂度：跨平台、跨分辨率、跨切片
- 技术难度：多级整合
- 生物学意义：系统性结论
```

**递进原则**：

```
任务递进原则：
1. 数据复杂度递增：单一 → 多来源 → 不完整 → 跨平台
2. 技术难度递增：简单 → 配准 → 推断 → 多级整合
3. 生物学意义递增：技术验证 → 应用 → 新发现 → 系统性结论
4. Figure 对应：Level 1 → Figure 2, Level 4 → Figure 5
```

- 数据完整性：[完整/部分缺失/...]

**技术要点**：
- 核心操作：[映射/配准/推断/整合]
- 关键挑战：[挑战描述]
- 预期效果：[效果描述]

**生物学意义**：
- 可验证什么：[技术指标]

## 示例：空间多组学整合的任务体系

```markdown
### Task 1: 垂直整合

**定义**：同一细胞/spot的多模态数据整合

**难度**：Level 1（低）

**数据要求**：
- 数据类型：RNA + Protein（或其他模态组合）
- 数据来源：同一组织切片
- 数据完整性：完整（所有细胞都有所有模态）

**技术要点**：
- 核心操作：直接 concat / weighted averaging
- 关键挑战：模态间尺度差异
- 预期效果：整合后 latent representation

**生物学意义**：
- 可验证什么：整合质量（ARI、NMI）
- 可发现什么：细胞类型空间分布

**典型方法**：
- MOFA+：因子分析
- totalVI：深度生成模型

**对应 Figure**：Figure 2

---

### Task 2: 水平整合

**定义**：不同区域/切片的空间数据配准整合

**难度**：Level 2（中）

**数据要求**：
- 数据类型：RNA（或其他单模态）
- 数据来源：相邻切片或连续切片
- 数据完整性：完整

**技术要点**：
- 核心操作：空间配准 + 整合
- 关键挑战：切片间形态差异、配准准确性
- 预期效果：配准后的整合 representation

**生物学意义**：
- 可验证什么：配准准确度（MSE）
- 可发现什么：连续切片的完整组织结构

**典型方法**：
- PASTE：切片配准
- STalign：形态配准

**对应 Figure**：Figure 3

---

### Task 3: 马赛克整合

**定义**：部分细胞有部分模态，推断缺失模态

**难度**：Level 3（高）

**数据要求**：
- 数据类型：多模态
- 数据来源：同一切片，但部分测量
- 数据完整性：部分缺失

**技术要点**：
- 核心操作：推断缺失模态 + 整合
- 关键挑战：缺失模态的准确推断
- 预期效果：推断 + 整合后的 representation

**生物学意义**：
- 可验证什么：推断准确度（Pearson r）
- 可发现什么：完整的多模态信息

**典型方法**：
- imputation-based methods

**对应 Figure**：Figure 4

---

### Task 4: 对角整合

**定义**：跨切片、跨模态、跨分辨率的整合

**难度**：Level 4（最高）

**数据要求**：
- 数据类型：多模态
- 数据来源：不同切片、不同平台
- 数据完整性：部分缺失 + 分辨率不一致

**技术要点**：
- 核心操作：跨切片配准 + 跨模态推断 + 跨分辨率整合
- 关键挑战：三维挑战叠加
- 预期效果：完整整合后的 representation

**生物学意义**：
- 可验证什么：整体整合质量
- 可发现什么：跨模态调控机制、新的生物学发现

**典型方法**：（较少，这是创新点）

**对应 Figure**：Figure 5
```

## 使用方式

```bash
/bio-task-system "空间多组学整合 | paper_count: 5"
```

## 注意事项

1. **任务层级必须递进**：确保 Level 1-4 难度递增
2. **Figure 对应**：Level 1 → Figure 2, Level 4 → Figure 5
3. **创新任务**：Level 4 往往是方法创新点
4. **生物学意义**：每个任务都要说明可验证/可发现什么
